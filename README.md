# RegistreAi

Repositório oficial do novo projeto RegistreAi.

## Site
- React + Vite + TypeScript
- Supabase: `registreai` (`qxgfkpqlaffsesqtnojh`)
- Deploy: Hostinger
- Branch de produção: `main`

## Build
```bash
npm install
npm run build
```

Saída de produção: `dist/`.

## Variáveis públicas
Copie `.env.example` e configure:
- `VITE_SUPABASE_URL`
- `VITE_WHATSAPP_NUMBER`

Nunca versionar chaves privadas, tokens, service role, Meta, Asaas ou OpenAI.
